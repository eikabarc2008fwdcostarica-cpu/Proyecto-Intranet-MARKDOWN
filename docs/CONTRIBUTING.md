# Contribución al Proyecto

## Flujo básico

1. Crear una rama a partir de `main`.
2. Realizar cambios pequeños y relacionados.
3. Hacer commits descriptivos.
4. Subir la rama al repositorio.
5. Crear un Pull Request antes de integrar cambios a `main`.

## Ramas sugeridas

```text
feature/auth-usuarios
feature/modulo-academico
feature/comunicados-ui
```

## Commits

Usar mensajes breves que indiquen claramente el cambio realizado.

```text
feat: agrega formulario de usuarios
fix: corrige validacion de calificaciones
docs: actualiza requerimientos
```

> Este archivo se mantiene deliberadamente simple en la versión inicial y podrá ampliarse cuando el equipo defina su flujo definitivo de trabajo.
